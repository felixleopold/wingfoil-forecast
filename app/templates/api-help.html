Overview

The Wingfoil Forecast API provides real-time weather data and advanced wingfoil condition analysis using a sophisticated 4-pillar scoring system. All endpoints return JSON data and support CORS for web applications.

Base URL: https://wingfoil.felixmrak.com
Content-Type: application/json
Authentication: None required for read endpoints

V2 Scoring Algorithm

The service uses an advanced 4-pillar scoring system that provides transparent, skill-adaptive wingfoil condition analysis:

Overall Formula

Overall = clamp(100 × (0.60×Wind + 0.20×Surface + 0.15×Safety + 0.05×Comfort) × Confidence, 0, 100)

Pillar Breakdown

Pillar Weight Components Description
Wind 60% Speed, Direction, Consistency Gaussian speed scoring, shore alignment, gust penalties
Surface 20% Wave Quality, Chop, Current Wave steepness, wind-sea interaction, tidal effects
Safety 15% Gust Factor, Weather, Visibility Gust consistency, precipitation, wind-chill, visibility
Comfort 5% Temperature, Rain, Humidity Thermal comfort, precipitation, humidity levels

Skill Level Adaptation

Skill Level Wind Range (m/s) Optimal Range (m/s) Safety Factors
Beginner 6-16 9-13 Offshore wind caps, enhanced safety
Intermediate 7-18 10-15 Standard safety factors
Advanced 8-22 11-18 Reduced safety penalties

Score Interpretation

Score Range Conditions Description
85-100 Excellent Perfect conditions for wingfoiling
70-84 Good Great conditions with minor limitations
60-69 Marginal Rideable but challenging conditions
0-59 Poor Not recommended for wingfoiling

Error Handling

All endpoints return appropriate HTTP status codes and error messages:

Status Code Description Example Response
200 Success Data returned successfully
400 Bad Request Invalid parameters or request body
401 Unauthorized Missing or invalid admin token
404 Not Found Endpoint or resource not found
500 Internal Server Error Server error or API failure

Error Response Format

Example Error Response

{
  "error": "Invalid latitude value",
  "message": "Latitude must be between -90 and 90 degrees",
  "status": 400
}

Rate Limiting

The API implements intelligent caching to minimize external API calls:

  • Current Conditions: Cached for 30 minutes
  • Hourly Forecast: Cached for 1 hour
  • 5-Day Forecast: Cached for 6 hours
  • Configuration: No caching
Note: Rate limiting is handled automatically through caching. No explicit rate limits are enforced.
